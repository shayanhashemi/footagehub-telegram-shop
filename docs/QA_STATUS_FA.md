# وضعیت اعتبارسنجی این نسخه

**بررسی‌شده در محیط تولید سورس:**

- استخراج کاتالوگ با `artifact_tool` از Excel بارگذاری‌شده: ۷ گروه، ۲۹ دسته، ۵۷۰ زیردسته؛ کد زیردسته‌ها یکتا.
- مجزا بودن English Fonts و Persian Fonts در شاخه ۲۴.
- بررسی نحوی فایل‌های TypeScript و TSX با ترنسپایلر TypeScript: بدون خطای parse.
- اجرای تست‌های مستقل با Node.js: قوانین انتشار محصول، اعتبارسنجی هاست دانلود، اعتبار و انقضای توکن امضاشده، و صحت تعداد دسته‌ها.
- وجود دو رکورد محصول با لینک‌های ارسالی، در حالت Draft و بدون قیمت ساختگی.

**آزمایش‌های ضروری پیش از تحویل عملیاتی (هنوز در این محیط اجرا نشده):**

1. اتصال به MySQL 8؛ `npm install`، `npm run db:generate`، `npm run db:migrate`، `npm run db:seed`، `npm run build` و `npm run typecheck`.
2. ورود و خروج مدیر، افزودن/ویرایش و انتشار محصول با حقوق بازنشر معتبر، بارگذاری کاور و لینک ZIP/RAR واقعی.
3. اجرای ربات با BotFather token؛ پیمایش چندسطحی، جستجو، زبان، دکمه‌های غیرفعال بانکی و عدم نمایش پیش‌نویس‌ها.
4. خرید آزمایشی واقعی Stars: تأیید pre_checkout، دریافت successful_payment، ثبت unique charge id، مشاهده در My Purchases و دانلود مجدد.
5. استرداد واقعی Stars و اطمینان از عدم دسترسی پس از Refund (مگر خرید موفق دیگری وجود داشته باشد).
6. عضویت رسمی PRO از طریق اشتراک کانال خصوصی، بررسی عضویت و انقضای آن.
7. آزمون دانلود با HTTPS و reverse proxy: فایل‌های بزرگ، Range، قطع اتصال، لینک منقضی، فایل غیرمجاز، و رد هاست خارج از allowlist.
8. تست فشار، پایش، پشتیبان‌گیری از MySQL و رسانه‌ها، ارزیابی امنیتی و راه‌اندازی لاگ چرخشی.

**دلیل محدودیت:** محیط تحویل سورس به رجیستری npm و دیتابیس/توکن واقعی دسترسی نداشت؛ لذا تأیید فنی کامل production قابل ادعا نیست.
